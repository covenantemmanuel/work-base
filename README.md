# FinFlow Dashboard

Production-grade Next.js 15 fintech/social platform starter featuring:
- Firebase auth with email verification, forgot password, persistent sessions
- Firestore profile lifecycle and analytics-ready collections
- Premium dashboard UI with Tailwind, motion, dark mode foundation
- Admin area scaffold, chat module scaffold, Paystack verify endpoint scaffold
